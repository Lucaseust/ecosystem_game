# Project review — 31 October 2026

Reviewed the narrative campaign, launcher, HTTP boundary, persistence, browser rendering, French/English copy, rules, debrief/export paths and distribution. The archived engine retains its regression coverage. No real classroom save was edited, no repository was initialised and nothing was published.

## Findings and changes

| Area | Finding | Result |
| --- | --- | --- |
| Static files | String-prefix containment could admit a sibling directory beginning with `web`. | Resolved-path containment confines responses to the asset directory, including symlink resolution. |
| HTTP input | Non-object JSON, invalid types, unbounded bodies and invalid timer values could reach the engine or consume resources. | Object/type/size validation, bounded timer additions, transfer/content-type checks and clear 4xx responses. |
| Request abuse | Threads and failed authentication had no application-level bound. | 128 concurrent handlers, read timeouts, bounded rate limits, cross-origin POST checks and response security headers. |
| Credentials | Instructor keys appeared in routine browser query requests and launcher preferences. | Current clients use authorisation headers, clear the initial key from the address bar, authenticate export fetches and omit keys from preferences. Saved sessions retain credentials for resumption and stay outside the release. |
| Persistence | A background snapshot could be written after a newer synchronous decision. | Campaign initial state and decisions save synchronously under the game lock. Delayed saving is limited to legacy play and holds the lock through the write. Atomic files are flushed before replacement. |
| Save errors | Invalid latest saves could silently lead to a new game; final save failure could exit successfully. | Explicit startup failure preserves unreadable saves; failed final saves return a failing exit status. |
| Supplier capabilities | A replaced AUTO/FLEET could retain preparation discounts; replaced FLEET could reduce expansion risk. | Benefits require the original company to supply the activity. Earlier spending remains recorded. |
| Automated decisions | Standardising a suspended service could be evaluated using revenue from a service that would remain suspended. | Automated companies consider outside activity and the actual contribution in this case. |
| Language | The campaign was French-only. | Session-wide French/English, local presentation catalogue, copied API view translation and embedded offline-report translation. Numbers, protocol values and player text stay unchanged. |
| Copy | Current company briefs inherited unaccented historical wording and unused legacy fields. | Corrected French, clearer contractual wording and only the needed brief in campaign views. English covers current controls, briefing, decisions, events, errors and debrief. |
| Maintainability | Dense statements; no project-owned lint/release configuration. | Python formatting/lint rules, readable current campaign control code, separate HTTP/localisation modules, contributor instructions and CI definition. |
| Distribution | Working folder contains local sessions/preferences and a large tunnel executable. | Allowlisted ZIP, SHA-256 manifest, ignore rules, portable entry point, bilingual setup guide and owner-selected GPL-3.0-only licence. Local originals remain on disk. |

The tunnel command file now directs users to the official Cloudflare installation instead of downloading an executable into the project. Cloudflared remains optional and outside the release.

## Rules and challenge

The review retains the one-off 20-credit allocation, private economics, required unanimous consent, revision invalidation, sunk costs, calendar deadlines, outside opportunities and independent local events. It adds no suggested revenue split, solution or future-event preview to player screens. Numerical calibration is unchanged; the capability fixes enforce the described company roles.

Checked integer accounting, distribution of actual revenue, the substitute as an external cost, four quarterly settlements, request replay protection, private response/shock gating and preservation of historical entries. The English instructor reference also clarifies that later shared-interface investment does not undo a delay already committed earlier in that quarter.

## Practical limits

This is a supervised session server built on `http.server`, not an independently penetration-tested Internet service. Use a trusted LAN or temporary HTTPS tunnel and keep the instructor link private. [Python warns against production use of this server](https://docs.python.org/3/library/http.server.html); [Cloudflare Quick Tunnels are temporary and have no uptime guarantee](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/). Live public tunnel availability and institutional Wi-Fi/firewall conditions were not tested. Local checks do not establish behaviour on every phone, browser or operating system.

The current campaign has full session-language selection. Historical `--legacy` play retains its original French interface. Raw exports retain stable fields and original recorded wording. Player messages can contain personal information if participants type it; source releases exclude session exports and saves.

Publish the generated ZIP or initialise a repository from its extracted contents. Uploading the entire original working directory bypasses those exclusions. The full GPL-3.0-only terms are in `LICENSE`; optional development/tunnel tools are distributed separately under their own licences.
